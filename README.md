# Repet-AI

Интеллектуальная образовательная платформа для интерактивной подготовки к ОГЭ и ЕГЭ. Проект представляет собой мобильное ассистент-приложение, имитирующее живое общение с преподавателем на основе Сократического метода: система не выдает готовые ответы, а использует наводящие вопросы для развития аналитического мышления у ученика.

---

## 1. Концепция проекта

Основная задача платформы — уйти от механики пассивного списывания и зазубривания тестов. Внедренные решения:
* **Диагностический модуль (`app/test.tsx`):** Пошаговый мастер (Wizard) для первичной оценки знаний. На основе результатов ИИ формирует детальный аналитический отчет и подсвечивает пробелы в каталоге тем.
* **Интерактивный разбор задач (`app/solve.tsx`):** Двухрежимная отправка данных (Dual Mode). Режим `hint` (Нужна помощь) активирует наводящие подсказки ИИ, а режим `check` (Проверить) отправляет финальное решение на бэкенд.
* **Анализ хода мыслей:** Поле `student_thoughts` позволяет пользователю зафиксировать логику рассуждений. Агент анализирует текстовый путь решения, локализуя логическую ошибку, а не просто сверяет финальный численный ответ.
* **Элементы геймификации:** Удержание пользователя за счет трекинга активности (стрики непрерывных дней обучения) и динамических прогресс-баров по каждой учебной теме.

## 2. Технический стек

Приложение спроектировано по клиент-серверной архитектуре с прицелом на высокую производительность и минимальный TTFB на мобильных устройствах.

### Frontend & Mobile
* **Фреймворк:** React Native + Expo SDK для кроссплатформенной сборки под iOS и Android.
* **Роутинг:** Expo Router с файловой структурой страниц. Пространство разделено на строго изолированные группы: `(auth)` для авторизации, `(tabs)` для базовой навигации, а также выделенные экраны `/solve` и `/test`.
* **Безопасность:** Хранение авторизационных JWT-токенов в зашифрованном хранилище устройства через `Expo.SecureStore` с автоматическим редиректом при ошибке 401.
* **Рендеринг формул:** Кастомный компонент `MathText`, преобразующий разметку LaTeX и Markdown в нативный графический вид прямо на экране смартфона. Формулы вида:

$$\frac{-b \pm \sqrt{b^2 - 4ac}}{2a}$$

отображаются корректно и адаптируются под размеры дисплея.

### Backend & Инфраструктура
* **Язык и фреймворк:** Go (Golang) + Gin Gonic. Выбор обусловлен эффективной многопоточностью (горутины) для обработки параллельных запросов к API.
* **База данных:** PostgreSQL + ORM GORM. 
* **Безопасность:** Авторизация на базе короткоживущих токенов JWT, хеширование паролей пользователей с использованием Bcrypt.

### Искусственный интеллект и Медиа
* **Ядро ИИ:** Yandex Cloud AI Agents (YandexGPT 5.1). Используются агенты с системными промптами под Сократовский диалог и доступом к базе знаний через `file_search`.
* **Хранилище медиа:** Yandex Cloud Object Storage (S3) для хранения статических изображений, графиков и геометрических чертежей к задачам.

## 3. Архитектура данных и UX-логика

* **Локальное состояние Wizard-state:** Для предотвращения потери промежуточных ответов при навигации между шагами теста на клиенте развернуто индексируемое хранилище `Record<number, LocalAnswer>`. Данные отправляются одной пачкой методом POST только при завершении теста.
* **Динамический контекст ИИ-бокса:** Интерфейс блока ответов динамически меняет тему оформления и иконки (`Ionicons`) в зависимости от статуса ответа ИИ:
  * *Теплый желтый фон* — подсказка (Hint), снижающая страх совершить ошибку.
  * *Зеленый фон* — правильное решение, открывающее доступ к следующему шагу.
  * *Светло-красный фон* — фиксация ошибки, требующая переделки.

## 4. Структура базы данных (основные сущности)

```
├── Users (Профили, хэши паролей, сквозные метрики активности)
├── Topics (Дерево каталога тем с префиксами вида OGE_MATH_1)
├── Tasks (База заданий, эталонные ответы и уровень сложности)
└── User_Progress (Динамический скоринг уровня владения темой)
```

## 5. Локальный запуск

### Предварительные требования
Для работы бэкенда лакально должен быть запущен и доступен сервер PostgreSQL. Создавать таблицы вручную не требуется: при старте бэкенд автоматически выполнит миграци структуры данных через GORM AutoMigrate.

### Инструкция по запуску

1. **Запуск Бэкенда (Go):**
```bash
   cd backend
   go mod download
   go run main.go
```

2. **Запуск Фронтенда (React Native / Expo):**
```bash
   cd frontend
   npm install
   npx expo start
```

После запуска Expo CLI отсканируйте сгенерированный QR-код через приложение Expo Go на мобильном устройстве для тестирования интерфейса.
